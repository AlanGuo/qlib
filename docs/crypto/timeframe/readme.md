## ⚠️ 重要概念

### 统一格式原则
- **用户侧**：始终使用 `1h`, `1d`, `1w` 等标准格式
- **文件系统**：目录和文件都使用标准格式
- **内部转换**：仅在必要时进行，且严格限制使用范围

### 边界分离设计
- **用户接口**：简单一致的标准格式
- **存储层**：统一的目录和文件命名
- **Qlib兼容层**：内部转换，对用户透明

### OKX 特别提醒
- **正确格式**: `1h`, `1d`, `1w` (小写)
- **错误格式**: `1H`, `1D`, `1W` (大写) - 会导致API错误
- **重要性**: 这是常见的错误假设，请务必注意
